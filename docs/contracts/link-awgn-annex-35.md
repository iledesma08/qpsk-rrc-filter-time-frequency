## Proposed Decisions

The following are proposed (not yet accepted):

- **D1 — Analysis-only boundary:** the annex is a `sim/python/` script (for
  example `link_awgn.py`) plus plots. It MUST NOT modify `sim/vectors/`,
  any RTL source, any testbench, or the stimulus/FXP/streaming contracts
  (#13–#19), and it MUST NOT become a DoD of any phase.
- **D2 — Dual-arm chain:** bits → bit labeling of D8 (`Es = 2`) → TX
  shaping with the ideal/long RRC defined below → complex AWGN at a
  declared `Es/N0` → RX filtering → symbol sampling → slicer (inverse D8
  rule) → BER count. The chain runs twice, identically except for the RX
  arm: (a) float-golden arm (reference/theory curve) and (b) FXP-model arm
  (the T20 model at the accepted `W_common`), whose gap to theory is the
  **implementation loss**. Without arm (b) the annex would speak about the
  design, never about the delivered hardware.
- **D2b — TX pulse (ideal/long):** TX uses the same closed-form RRC family
  as #13 (`alpha = 0.5`, `T = 1`) evaluated on a long grid (proposed span
  ±8 symbols at 2 sps, L2-normalized, generated by formula and documented
  with its exact span/tap count). It is deliberately NOT the contractual
  8-tap filter. Justification, recorded here so the choice is never
  revisited silently: 8 taps are a heavily truncated pulse, so an 8-tap
  TX/RX pair is not exactly Nyquist; the residual ISI would put a BER floor
  under the curve that the `Q(sqrt(Es/N0))` theory (which assumes zero ISI)
  cannot predict, and no reader could tell filter fault from TX truncation.
  Measuring the 8-tap RX (golden and FXP) against an ideal/long TX isolates
  exactly the truncation-plus-quantization loss of the delivered filter,
  which is the interesting question.
- **D3 — Noise model:** circular complex AWGN with total variance `N0`,
  i.e. `N0/2` per I/Q component, where `N0 = Es / (Es/N0)_lin` with the
  contractual `Es = 2` (`qpsk-stimulus-15.md` Signal Model). The PRNG stream
  uses a fixed documented seed distinct from the stimulus seed (proposed
  `numpy.random.default_rng(2035)`) so link runs can never be confused with
  contractual vectors.
- **D4 — Symbol timing and assumed-ideal list:** pulse centers sit at
  `2k + 3.5` samples (#15 D7), so the slicing instant requires
  interpolation. Interpolation here is part of the analysis model and MUST
  be labelled as such; it is never presented as implementation output.
  Assumed ideal, stated explicitly so plots cannot be over-read: perfect
  timing recovery (sampling at true centers), zero frequency/phase offset,
  zero phase noise, zero I/Q imbalance, AWGN as the only impairment. The
  claim scope is therefore the filter in isolation under ideal
  synchronization — never "our receiver links at X dB".
- **D5 — Statistical significance:** each `Es/N0` point MUST accumulate at
  least 100 bit errors (or document a justified equivalent), with enough
  transmitted bits to support the claimed BER. The 1024-symbol canonical
  frame is explicitly insufficient for BER and MUST NOT be reused for it;
  link runs use their own long frames, separate from the canonical SQNR
  frame.
- **D6 — Theory reference and implementation loss:** Gray-coded QPSK
  `BER_theory = Q(sqrt(2*Eb/N0)) = Q(sqrt(Es/N0))`, consistent with `Es = 2`
  (`Es = 2*Eb` for QPSK) and valid only under the D2/D4/D8 assumptions
  (near-Nyquist pair, correct timing, exact Gray/bit rule). Implementation
  loss is the horizontal gap, in dB, between the FXP arm and theory at the
  reference BER point (proposed lowest significant plotted point, e.g.
  `1e-3`), documented per plot. EVM, when plotted, follows the #18
  definition (RMS vector error versus the float golden output).
- **D7 — Deliverables:** BER-versus-theory curve plus constellation plots
  for `docs/slides/` material. Suggested (non-normative) sweep:
  `Es/N0 = {0, 2, 4, 6, 8, 10}` dB.
- **D8 — Bit labeling for BER:** the symbol carries the ordered pair
  `[b1, b0]`, MSB first in the bit stream, with `b1 = 0 → I = +1`,
  `b1 = 1 → I = -1`, `b0 = 0 → Q = +1`, `b0 = 1 → Q = -1`, i.e.

  ```text
  00 -> +1+j    01 -> +1-j    10 -> -1+j    11 -> -1-j
  ```

  Constellation-adjacent symbols (differing only in I or only in Q) differ
  in exactly one bit (Gray, verifiable from the table). The slicer inverts
  this rule and BER counts errors on the `[b1, b0]` stream. Without this
  table two annex implementations would count different BERs; the #15
  `idx -> corner` mapping alone does not define bits.

## Decision Rationale

### D1 — Analysis-only boundary

- **Alternatives:** let the annex drive RTL vectors; make BER a phase DoD.
- **Why they are rejected:** AWGN in vectors would break deterministic
  bit-exact matching (the core F2/F3 verification); a BER DoD requires a
  full timed chain with significance the current plan does not budget.
- **Why this is proposed:** it preserves every frozen contract while still
  allowing the "right filter, not just bit-exact" argument in F5.

### D2/D2b/D3 — Dual-arm chain, ideal/long TX, noise model

- **Alternatives:** float-golden RX only; TX with the contractual 8-tap
  filter ("same RRC both ends"); TX with an ideal sinc or a different
  roll-off; noise variance referenced to `Es = 1`.
- **Why they are rejected:** a float-only annex proves the design links but
  says nothing about the delivered fixed-point hardware; an 8-tap TX/RX
  pair is heavily truncated, hence not exactly Nyquist, so residual ISI
  floors the BER where the zero-ISI theory cannot follow — the resulting
  theory gap would be uninterpretable (filter fault or TX truncation?); a
  different TX pulse breaks the matched condition silently; `Es = 1` would
  contradict the contractual `Es = 2` and force a second scale convention.
- **Why this is proposed:** the dual arm turns the annex into an
  implementation-loss measurement (the production argument); the ideal/long
  TX isolates truncation-plus-quantization loss of the 8-tap RX instead of
  hiding an ISI floor; `N0 = Es/(Es/N0)` with `Es = 2` keeps one energy
  convention across stimulus, analysis, and theory.

### D4 — Timing interpolation and assumed-ideal list

- **Alternatives:** slice at the nearest integer sample; forbid
  interpolation entirely; leave impairments unstated.
- **Why they are rejected:** the nearest sample is up to half a sample off
  the true center and would corrupt the BER with a timing error; forbidding
  interpolation makes slicing impossible on this grid; unstated impairments
  let plots be read as receiver claims instead of filter-in-isolation
  results.
- **Why this is proposed:** the interpolation is analysis machinery, not
  evidence of implementation output, and labelling keeps that distinction
  auditable (same spirit as #15 D7); the explicit ideal list bounds the
  claim exactly the way production link documentation does.

### D5 — Significance rule

- **Alternatives:** reuse the canonical 1024-symbol frame; accept any error
  count.
- **Why they are rejected:** ~2048 bits cannot support BER claims below
  ~1e-2 with any confidence; an unjustified point is worse than no point.
- **Why this is proposed:** the 100-error floor is the standard
  order-of-magnitude rule that makes each plotted point defensible, and
  separating link frames protects the canonical frame's SQNR role.

### D6/D7 — Reference and deliverables

- **Why this is proposed:** the closed-form QPSK bound is only valid under
  the exact Gray/bit rule, near-Nyquist TX/RX pair, and correct timing
  defined above; stating it here binds the plots to their assumptions. The
  Es/N0 set is illustrative; the significance rule, not the set, is
  normative.

### D8 — Bit labeling

- **Alternatives:** reuse the #15 `idx -> corner` mapping as-is for BER.
- **Why it is rejected:** that mapping assigns indices, not bits; without an
  explicit bit rule two annex implementations count different BERs and the
  Gray property is unverifiable.
- **Why this is proposed:** the `[b1, b0]` table fixes bit order, corner
  assignment, and Gray adjacency in four lines, making every BER number
  reproducible and comparable.

## Acceptance Gate for the Annex

The annex is accepted for F5 use only when:

- the dual-arm chain, TX definition, noise model, seed, timing
  interpolation, assumed-ideal list, and bit labeling are documented as
  above;
- every plotted `Es/N0` point meets the D5 significance rule on both arms;
- implementation loss is reported per D6 at the reference BER point;
- no file under `sim/vectors/`, `rtl/`, or `rtl/tb/` is modified or added
  by the annex work;
- no phase DoD is reinterpreted through BER.

If the annex is never built, this contract stays dormant and no phase is
blocked.
