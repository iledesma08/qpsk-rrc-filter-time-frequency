# GitHub Issues, single context, Conventional Commits

Work in GitHub Issues with 5 canonical triage labels, a single root `CONTEXT.md` plus ADRs in `docs/adr/`, Conventional Commits with scope, and `type/<issue>-description` branches.

This is the simplest combination supporting 4 people + agents without duplicating glossaries or trackers.

Considered Options: Jira/Linear (overkill for coursework), multi-context with CONTEXT-MAP (no monorepo here), GitFlow (heavy; GitHub Flow with protected `main` is used instead).
